# XR-Bartending

Project Idea

The proposed project is an interactive XR bartending simulator developed using Godot. The experience will place the learner behind the counter of a virtual bar, where they will learn the fundamentals of preparing cocktails through practical, hands-on interactions and create some of my and their favourite drinks !

The environment will resemble a traditional bar, with bottles, glasses, bartending equipment, and atmospheric features such as lighting, music, and potentially the user can use the bar's ashtray if they find they need a virtual break.

What Will the Learner Learn?

The experience aims to teach the learner basic bartending skills such as pouring pints or mixing cocktails. By completing the experience, the learner should be able to:

Identify common bartending equipment and understand its purpose.

Recognise the ingredients required for selected cocktails

Understand basic measurements and ingredient proportions

Follow the correct sequence of steps when preparing a cocktail

Apply their knowledge to prepare any drink they like

Godot Engine: Main game engine used to develop the XR environment.

OpenXR: Integration with XR headsets and controllers.

Godot XR Tools: Interactions such as grabbing, holding, and releasing bottles, glasses, and bartending equipment.

Godot OpenXR Vendors: Potential support for hand tracking and controller-free interactions.

GDScript: Managing cocktail recipes, user interactions, and learning progression.

Godot Physics: Interactions between physical objects within the bar.

Particles and Tweens: Visual effects for pouring liquids, mixing drinks, and environmental details.

Spatial Audio: Environmental sounds and audio feedback during interactions.
